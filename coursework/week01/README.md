# Dart: отдельные задания недели 1

Дополнено **16 октября 2026 при подготовке к РК1**, без утверждения о сдаче в прошлые недели. Точная исходная методичка преподавателя не предоставлена; ниже самостоятельный комплект по базовым темам Dart. Существующий краткий пример — [dart_basics.dart](../../docs/dart_basics.dart).

| Задание | Условие | Реализация |
| --- | --- | --- |
| 1 | Преобразовать балл 0–100 в буквенную оценку, отклонить неверный ввод | `grade`, switch expression, RangeError |
| 2 | Посчитать частоты слов, пропустить null/пустые значения | `frequencies`, Map, цикл, null safety |
| 3 | Создать неизменяемую задачу с завершением через новый объект | `StudyTask`, named constructor, getter, override |
| 4 | Асинхронно получить заголовок через внедряемый источник | `loadTitle`, Future/await, timeout, FormatException |
| 5 | Выдать поток накопительных сумм | `runningTotal`, Stream, async*, await for |

```sh
dart run coursework/week01/exercises.dart
dart run docs/dart_basics.dart
flutter test test/coursework_test.dart
```

Проверки охватывают границы, null, неизменяемость, пустой ответ, ошибку источника, timeout и отрицательные числа в потоке. Учебные числа не используются для данных качества воздуха.
