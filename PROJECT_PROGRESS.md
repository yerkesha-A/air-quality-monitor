- Android: прежние подписанные APK/AAB 1.1.0 (3), ключ и данные сохранены. По текущему указанию Android не меняется и не переустанавливается.
- iOS: Xcode 27.2, чистая Swift Package Manager интеграция, реальный Simulator-прогон API/SQLite/Swift-канала пройден. Новый согласованный ID `kz.erkezhan.airqualitymonitor` зарегистрирован в прежнем Firebase, Google callback согласован; подписанная iPhone Release AOT 1.1.1 (4) проверена и установлена поверх debug без удаления. Камера/GPS без ошибок по проверке владельца; выбор из галереи и фото после перезапуска подтверждены.

- GitHub: последний опубликованный checkpoint `552bb11`, [Actions success](https://github.com/yerkesha-A/air-quality-monitor/actions/runs/45630653658). Текущие правки локальны; новый push и доставка App Distribution требуют разрешения.
