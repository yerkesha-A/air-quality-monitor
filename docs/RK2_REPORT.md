## Безопасность

Основной AVD не используется для этих испытаний. Новые проверки выполняются на AQM_Memory_Baseline и резервно скопированном AQM_Release_Check. Wipe data, uninstall, очистка SQLite, смена ключа, billing и публикация не выполнялись. Локальная контрольная точка перед изменением карты — коммит 003efef; дополнительная копия изменений хранится в игнорируемом .local-backups.
