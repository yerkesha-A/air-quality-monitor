## Как показать приложение

Предпочтительно открыть установленный **iPhone Release 1.1.1 (4)** с главного экрана. Mac и debugger для запуска не нужны. Google-сессия и фото сохраняются после полного закрытия. Бесплатная development-подпись действует до **03.12.2026, 15:54 UTC**; позднее требуется обновление через Mac с теми же Team и Bundle ID.

Показать главную и время Open-Meteo, карту и легенду, историю/заметки, избранное, тему, профиль. Камера добавляет снимок в заметку; галерея доступна в «Профиль → Аккаунт → Изменить фото». Настоящий аккаунт на защите не удалять.

Альтернатива — заранее подготовленный лёгкий Android AVD API 30, 2048 MiB, 2 CPU. Во время демонстрации не собирать проект и не запускать второй Simulator/AVD. Не очищать данные и не выходить из аккаунта ради демонстрации.

Для свежих запросов нужен интернет. Без сети показываются сохранённые данные с исходным временем; скриншоты служат запасным материалом. [Инструкция для MacBook](../rk2/MAC_DEMO.md).
