1. **Android APK** `submission/FINAL_RK1_RK2_2026-11-23/android/air-quality-monitor-1.1.0-3.apk` — устанавливаемая подписанная версия. AAB не предназначен для прямой установки.
2. **Презентация PDF** `docs/rk2/RK2_PRESENTATION.pdf`; при необходимости редактирования — соседний PPTX.
3. **РК1** `RK1_REPORT.md` — задания недель 1–7; **РК2** `docs/RK2_REPORT.md` — недели 8–15.
4. **Матрица проверки** [все 15 недель](AUDIT_01_15.md) и [13 требований](../REQUIREMENTS_AUDIT.md), с исходниками и доказательствами.
5. **Исходники** из локального комплекта и ссылка на [GitHub](https://github.com/yerkesha-A/air-quality-monitor). Исходники и материалы финального аудита обновлены с разрешения владельца; CI приложения 45228891410 прошёл успешно.

В итоговом каталоге сохраняются контрольные суммы и локальный архив исходников. В него не входят приватный keystore, пароли, токены CLI, данные аккаунтов, AVD и резервные копии.

## Перед показом

Открыть готовый APK на одном лёгком AVD API 30 / 2048 MiB / 2 CPU. Во время демонстрации сборку не запускать. Показать главную и время данных, карту, группу точек, раскрытие карточки и легенду, историю, тему, профиль с уже сохранённой тестовой сессией. Не выходить из аккаунта и не очищать данные ради демонстрации.

Для нового запроса нужны интернет и доступность Open-Meteo/OSM/Firebase. Без интернета показывать только ранее сохранённые данные с исходным временем. Скриншоты — запасной материал, а не доказательство текущего онлайн-запроса.

[Сценарий на 9–10 минут](../rk2/DEFENSE.md), [13 вопросов](../rk2/QUESTIONS.md), [инструкция для MacBook](../rk2/MAC_DEMO.md).

## Что сказать об ограничениях

- Используется OpenStreetMap. Это работающая бесплатная замена, но дословное требование Google Maps нужно согласовать с преподавателем.
- Физического Android сейчас нет; настоящая камера/GPS телефона и физическая установка App Distribution не проверены.
- Старые Play Services лёгкого API 30 ограничивают свежую Google Sign-In приёмку. Release SHA и provider проверены; прежний успешный Google-вход подтверждён владельцем, свежий финальный вход не заявляется.
- Профилирование реально выполнено; стабильные 60 FPS и отсутствие утечек одним прогоном не доказаны.
- CI исходников приложения `79bca13` прошёл: run 45228891410. App Distribution содержит предыдущий build 2; новая доставка build 3 требует разрешения. Google Play не публиковался.
