# Демонстрация недель 9–11 — около пяти минут

1. **Главная, 40 секунд.** Выбрать Алматы, показать настоящий AQI, время обновления, прогноз; объяснить Open-Meteo/CAMS и кеш при отсутствии сети.
2. **Карта, 50 секунд.** Если Cloud ещё не настроен, прямо назвать этот пункт незавершённым. Показать код Maps SDK, контроллер debounce/кеша и тесты разрешений. После настройки показать настоящие маркеры, карточку PM₂.₅/PM₁₀, GPS, отказ и тёмную тему. Экран-заглушка не доказывает работающую карту.
3. **Производительность, 90 секунд.** Открыть список заметок/уведомлений с несколькими порциями. Прокрутить до следующей порции без кнопки; показать загрузку и конец. Открыть WEEK_10.md и настоящие Performance/Memory до/после. Объяснить lazy slivers, keyset SQLite, cached_network_image для сетевого Google-аватара и RepaintBoundary графика.
4. **Нативные возможности, 80 секунд.** На авторизованном тестовом устройстве: Профиль → аккаунт → Изменить фото → Сделать снимок; подтвердить фото. Затем выбрать фото из галереи, отменить повторный выбор. Полностью закрыть приложение, открыть и показать тот же аккаунт и аватар. Профиль → информация об устройстве: модель, Android SDK, батарея из собственного Kotlin MethodChannel.
5. **Качество, 40 секунд.** Показать результаты анализа, тестов и покрытия. Разделить проверку эмулятора и физического телефона; не утверждать, что телефон проверен, если он не подключался.

Основной AVD не использовать для экспериментов с тестовыми данными. Для демонстрации до приёмки предпочтителен отдельный AQM_Weeks_09_11.
