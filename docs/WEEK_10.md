# Неделя 10. Производительность

Обновлено 16.11.2026.

## Реализация

В проекте используются ленивые списки, постраничная загрузка истории, cached_network_image для сетевых фотографий, ограниченный кэш и освобождение контроллеров.

Новый парный замер 16.11.2026: 745/1098 кадров; build p95 14,195/7,457 мс; raster p95 60,645/31,267 мс; heap после GC 18,30/18,51 MiB. ## Что осталось

Один парный прогон на эмуляторе не доказывает статистическую значимость, отсутствие утечек или стабильные 60 FPS. Сценарий включает главную, историю и профиль; карта исключена из сравнения, поскольку до изменения вместо неё была заглушка. Старые измерения сохранены отдельно.

Уточнение стенда: параметр запуска запрашивал 3072 MiB, но эмулятор API 37 автоматически увеличивал RAM до 4096 MiB (подтверждено исходными логами обоих прогонов). Manifest исправлен; сырые замеры и скриншоты не изменены. Это не измерения облегчённого API 30.

## Новая карта на лёгком API 30 — 23.11.2026

Проведён отдельный реальный парный profile-прогон старой (`86e2acd`) и новой (`556fde8`) карты: 2048 MiB, 2 CPU, 720×1600, одинаковые 12 жестов. Видимая высота карты выросла с 206,04 до 327 логических пикселей (+58,71%).

| Метрика | До | После |

Это **не доказательство общего ускорения**: raster p95 вырос. Новая карта рисует больше тайлов, кэш/сеть/GPU эмулятора и нагрузка MacBook не полностью контролируются. Один парный прогон не доказывает отсутствие утечек; результаты физического устройства отсутствуют. Снимки Performance включают прогрев, числовая таблица — отдельный измеряемый интервал жестов.
