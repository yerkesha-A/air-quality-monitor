# Неделя 11. Нативные возможности

Обновлено 16.11.2026.

## Реализация

Есть камера, галерея, локальное сохранение фотографии профиля и Kotlin MethodChannel для сведений об Android. Отмена и ошибки обрабатываются.

## Доказательства

16.11.2026 успешно пройдены два интеграционных запуска на Android API 37: MethodChannel (включая неизвестный метод), cached_network_image из диска при остановленном тестовом HTTP-сервере, реальный вход тестового Firebase-аккаунта, чтение Firestore с сервера, настоящее FCM-сообщение, камера и системная галерея. Второй запуск подтвердил сохранение UID и пути локальной фотографии, файл существует. [Обезличенный результат](rk2/evidence/native-verification.json). Предыдущие проверки сохранены в [архиве](weeks09_11/VALIDATION.md).

## Что осталось

Физического Android сейчас нет. Проверку камеры, разрешений и жизненного цикла на реальном устройстве пользователь отложил; она не считается выполненной.

[Полная матрица эмулятор/физическое устройство](rk2/DEVICE_VERIFICATION.md). iPhone не используется как подтверждение Android-тестирования. Остальная разработка и комплект защиты продолжаются без ожидания телефона.

## Повтор на лёгком API 30, 23.11.2026

Настоящие camera/gallery/MethodChannel проверены повторно. FCM получен с сервера, Firestore прочитан с `Source.server`; disk cache повторно декодировал изображение после остановки HTTP-сервера. Отдельный перезапуск сохранил тот же UID и локальный файл фото. [Обезличенный результат](final_audit/evidence/native-android.json). Физическое устройство по-прежнему не проверено.

Проверка FCM выявила отдельную ошибку общего SQLite-соединения между UI и background isolate. Фоновый handle отделён без изменения схемы и данных; подробности и приёмка — [финальный аудит](full_audit_weeks_1_15.md).
