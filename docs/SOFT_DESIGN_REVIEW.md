# Светлая доработка — первый этап для оценки

15 октября 2026. Checkpoint перед изменениями: `1d46a27`.

Объём этого этапа: главная, история, профиль, вход/регистрация, первый запуск
и минималистичная шторка выбора города. Отдельная доработка остальных страниц
ожидает оценки пользователя. Общие цветовые токены и поверхности уже применяются
существующими компонентами; API, база, Firebase и Google Maps не перенастраивались.

## Что изменилось

- Палитра: #F7FAFC, #DCEFF7, #B8DFED, #328FA3, текст #20343C.
- Верхняя фотография ограничена по высоте и плавно исчезает через ShaderMask
  поверх молочного фона. На обычных дополнительных страницах остаётся мягкий
  градиент без большого фото. Используются прежние локальные оптимизированные
  фотографии; новых сетевых запросов для фонов нет.
- Главная: светлая матовая карточка AQI с ограниченным 8 px blur; показатели,
  категория, шкала, рекомендации и прогноз сохранены. Загрязнители компактнее.
- История: убрана принудительная тёмная Theme и фотография на весь экран.
  Светлые карточки, фильтры, график, статистика, календарь, записи и заметки
  используют текущую системную/выбранную тему. Цвета категорий AQI сохранены.
  Оси графика используют onSurfaceVariant для читаемости в обеих темах.
- Профиль: тот же мягкий верхний фон, светлые поверхности и прежние действия.
- Вход/регистрация: фотографический верх, уменьшено визуальное выделение
  технического статуса Firebase, акцентные кнопки и поля с иконками.
  Кнопки проверяют данные и явно сообщают об отсутствии конфигурации;
  до подключения Firebase не выполняется фиктивный успешный вход.
- Первый запуск: на существующем /welcome кнопка «Начать» переключает
  AnimatedSwitcher к трём действиям: вход, регистрация, просмотр без аккаунта.
  Выбор сохраняет прежний флаг onboarded. Регистрация открывает тот же /login
  с mode=register. Завершённое приветствие не появляется при повторном запуске;
  восстановленный аккаунт также пропускает onboarding. Backend сессии не менялся.
- Выбор города: без фотографий, с иконками, страной, галочкой текущего места
  и независимой кнопкой избранного. Поиск, GPS, недавние и выбор сохранены.
- Тёмная тема: #10191F, тёмные поверхности и читаемый светлый текст;
  фотографии затемнены, навигация адаптируется.

## Проверки

- flutter analyze --no-pub: без замечаний.
- flutter test --no-pub: 45/45.
- Новый тест первого запуска: регистрация открывает настоящую форму,
  после пересоздания приложения завершённый onboarding не повторяется.
- Новый тест неподключённой auth: пустые поля показывают ошибки, валидный
  ввод не превращается в фиктивный успешный вход и не открывает /account.
- Сохранены проверки 320 px, шрифта 150%, keyboard inset 280 px,
  Next/Done, обеих тем, истории, поиска, избранного и штатной навигации.
- Debug APK собран для Android. Firebase cloud auth и подключённая карта
  не объявляются проверенными: соответствующие сервисы отложены.

Первый запуск и сценарий восстановления после перезапуска проверены widget-тестами,
без сброса пользовательских данных установленного Android-приложения.


Финальная native-приёмка: APK установлен поверх существующего приложения,
проверены обе темы и исправленные оси истории, открытие регистрации и QWERTY,
открытие CityPicker и повторный выбор текущего Almaty с возвращением на главную.
Четыре настоящие точки истории Almaty дали среднее 67.5 и максимум 71.0 US AQI.
Исходная светлая тема, выбранный город и локальные записи сохранены; история
возвращена на период 24 часа. Приложение оставлено на главной. Профиль, auth и
CityPicker сняты на сборке с тем же UI; итоговые снимки истории/главной обновлены
после единственной завершающей правки цвета осей графика.
