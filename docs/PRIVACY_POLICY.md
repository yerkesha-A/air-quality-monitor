# Политика конфиденциальности Air Quality Monitor

Обновлено: 25 ноября 2026. Разработчик приложения Air Quality Monitor. Контакт: **erkezhanabdraim@gmail.com**.

Air Quality Monitor — Android-приложение для просмотра модельных оценок качества воздуха. Мониторинг доступен без регистрации. Рекламных SDK и продажи пользовательских данных в приложении нет.

## Данные на устройстве

SharedPreferences и SQLite хранят тему, единицы, пороги предупреждений, выбранные места, избранное, историю, заметки и кеш воздуха. Выбранные фотографии профиля и заметок остаются в приватной папке приложения. Сетевое фото Google-профиля может кешироваться на устройстве. Для карты сохраняется ограниченный кеш тайлов; это не загрузка целого региона офлайн.

## Интернет и местоположение

Open-Meteo получает координаты выбранного города/точки для ответа о воздухе; его Geocoding API получает поисковую строку города. GPS запрашивается только по действию пользователя. Фонового отслеживания местоположения нет. Отказ от разрешения не мешает ручному поиску и просмотру карты.

OpenStreetMap получает запросы видимых картографических тайлов: из них определяется область просмотра. Сетевым сервисам также доступны обычные сведения HTTP, включая IP-адрес и идентификатор приложения. Подробнее: [политика OSMF](https://osmfoundation.org/wiki/Privacy_Policy), [Open-Meteo](https://open-meteo.com/en/terms).

## Аккаунт и Firebase

При регистрации/входе Firebase Authentication обрабатывает email, пароль либо Google-идентификацию; на настроенном iOS также Apple-идентификацию. Приложение не записывает пароль в Firestore, SQLite или журналы. SDK сохраняет сессию на устройстве для последующего входа.

Firestore хранит профиль (имя, email и при наличии URL Google-фотографии), настройки, выбранное место и избранное своего пользователя. Локальные фотографии не загружаются в Firebase Storage. При разрешении push сохраняется FCM-токен устройства. Без аккаунта облачная синхронизация недоступна. SDK Firebase могут автоматически создавать технические идентификаторы Firebase Installation/FCM. Отказ от отображения уведомлений сам по себе не означает отключение всей обработки технических данных SDK.

В release-сборке Firebase Crashlytics получает сведения об ошибках, версии приложения и устройстве. Пароли, содержимое заметок и локальные фотографии намеренно в отчёты не добавляются. Диагностика обрабатывается по [правилам Firebase](https://firebase.google.com/support/privacy); приложение не обещает удаление уже обезличенных диагностических агрегатов через выход из аккаунта.

## Разрешения

- Геолокация — для кнопки «Моё местоположение», только с разрешения.
- Системная камера/выбор фото — только после нажатия соответствующей кнопки; AQI не вычисляется по фотографии.
- Уведомления — для локальных предупреждений и разрешённых push. Отказ не блокирует мониторинг.

## Удаление аккаунта и связанных данных

Удаление запускается в приложении через Профиль → Аккаунт → «Удаление аккаунта», с отдельным подтверждением и повторной авторизацией. Удаляются Auth-пользователь, облачный профиль, настройки, избранное, регистрации устройств, уведомления и служебные claims, а также локальное фото профиля текущего аккаунта на этом устройстве. Общие локальные история, заметки с фото, избранное и настройки сохраняются для гостевого использования. Другие устройства не очищаются дистанционно.

Для защиты от повторной записи старыми сессиями хранится минимальная техническая отметка UID и времени без имени, email, фото и токенов. Поддержка удаляет её после завершения удаления Auth и истечения старых токенов (не ранее 2 часов); автоматический TTL не включён. Если удаление прервалось, повторите его после восстановления сети; приложение не выдаёт частичное удаление за успешное.

Альтернативный запрос: **erkezhanabdraim@gmail.com**, тема «Удаление аккаунта Air Quality Monitor», email аккаунта. **Не отправляйте пароль, токены или ключи.** Разработчик подтверждает владение аккаунтом и завершает обработку. [Подробная процедура](ACCOUNT_DELETION.md).

Выход из аккаунта не удаляет его. Локальные фотографии, история и заметки на других устройствах не удаляются удалённо: ими управляет владелец устройства. Удаление данных приложения через настройки Android или удаление приложения уничтожает его локальные данные; сначала сохраните нужные сведения. Новые запросы на удаление доступны и без установленного приложения через этот контакт.
