# Политика конфиденциальности Air Quality Monitor

Обновлено: 16 ноября 2026. Разработчик учебного проекта Air Quality Monitor. Контакт: **erkezhanabdraim@gmail.com**.

Air Quality Monitor — учебное Android-приложение для просмотра модельных оценок качества воздуха. Мониторинг доступен без регистрации. Рекламных SDK и продажи пользовательских данных в приложении нет.

## Данные на устройстве

SharedPreferences и SQLite хранят тему, единицы, пороги предупреждений, выбранные места, избранное, историю, заметки и кеш воздуха. Выбранные фотографии профиля и заметок остаются в приватной папке приложения. Сетевое фото Google-профиля может кешироваться на устройстве. Для карты сохраняется ограниченный кеш тайлов; это не загрузка целого региона офлайн.

## Интернет и местоположение

Open-Meteo получает координаты выбранного города/точки для ответа о воздухе; его Geocoding API получает поисковую строку города. GPS запрашивается только по действию пользователя. Фонового отслеживания местоположения нет. Отказ от разрешения не мешает ручному поиску и просмотру карты.

OpenStreetMap получает запросы видимых картографических тайлов: из них определяется область просмотра. Сетевым сервисам также доступны обычные сведения HTTP, включая IP-адрес и идентификатор приложения. Подробнее: [политика OSMF](https://osmfoundation.org/wiki/Privacy_Policy), [Open-Meteo](https://open-meteo.com/en/terms).

## Аккаунт и Firebase

При регистрации/входе Firebase Authentication обрабатывает email, пароль либо Google-идентификацию. Приложение не записывает пароль в Firestore, SQLite или журналы. SDK сохраняет сессию на устройстве для последующего входа.

Firestore хранит профиль (имя, email и при наличии URL Google-фотографии), настройки, выбранное место и избранное своего пользователя. Локальные фотографии не загружаются в Firebase Storage. При разрешении push сохраняется FCM-токен устройства. Без аккаунта облачная синхронизация недоступна.

В release-сборке Firebase Crashlytics получает сведения об ошибках, версии приложения и устройстве. Пароли, содержимое заметок и локальные фотографии намеренно в отчёты не добавляются. Диагностика обрабатывается по [правилам Firebase](https://firebase.google.com/support/privacy); приложение не обещает удаление уже обезличенных диагностических агрегатов через выход из аккаунта.

## Разрешения

- Геолокация — для кнопки «Моё местоположение», только с разрешения.
- Системная камера/выбор фото — только после нажатия соответствующей кнопки; AQI не вычисляется по фотографии.
- Уведомления — для локальных предупреждений и разрешённых push. Отказ не блокирует мониторинг.

## Удаление аккаунта и связанных данных

Чтобы запросить удаление облачного аккаунта и его данных, напишите на **erkezhanabdraim@gmail.com** с темой «Удаление аккаунта Air Quality Monitor». Укажите email аккаунта. **Не отправляйте пароль, токены или ключи.** Разработчик подтверждает владение аккаунтом, затем удаляет Firebase Authentication-пользователя, облачный профиль, настройки, избранное и зарегистрированные устройства. Обработка выполняется по запросу, а не автоматически при выходе.

Выход из аккаунта не удаляет его. Локальные фотографии, история и заметки на других устройствах не удаляются удалённо: ими управляет владелец устройства. Удаление данных приложения через настройки Android или удаление приложения уничтожает его локальные данные; сначала сохраните нужные сведения. Новые запросы на удаление доступны и без установленного приложения через этот контакт.
