## Безопасность

Основной AVD не используется для этих испытаний. Новые проверки выполняются на AQM_Memory_Baseline и резервно скопированном AQM_Release_Check. Wipe data, uninstall, очистка SQLite, смена ключа и подключение billing не выполнялись. Исходники опубликованы на GitHub и APK отправлен через App Distribution с разрешения владельца; Google Play не публиковался. Локальная контрольная точка перед изменением карты — коммит 003efef; дополнительная копия изменений хранится в игнорируемом .local-backups.

## Оставшиеся внешние проверки

Согласовать допустимость OpenStreetMap вместо Google Maps у преподавателя. Физическое Android-устройство сейчас недоступно: проверка отложена и не блокирует разработку, РК2 и защиту. App Distribution содержит сборку и согласованного тестировщика; это не подтверждает установку на телефоне. Push и тестовая доставка уже выполнены. [Матрица проверок и режим для MacBook 8 ГБ](../rk2/DEVICE_VERIFICATION.md).

## Проверка на облегчённом стенде 23 ноября

Release 1.1.0+2 работает на отдельном API 30 с фактическими 2 ГБ RAM и двумя CPU: карта получила реальные данные, история и тестовая Firebase-сессия сохранены после полного перезапуска процесса. Analyze без замечаний, 96/96 тестов, покрытие 72,83%. [Результат](../rk2/evidence/light-api30-20261123.json). App Distribution по API содержит 1.1.0 (2) и согласованного тестировщика; физическая установка не подтверждена. [Проверка распространения](../rk2/evidence/distribution-status-20261123.json).
