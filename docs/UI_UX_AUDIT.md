## Данные AQI

Open-Meteo отдаёт вычисленный US AQI и концентрации; приложение не вычисляет заново EPA breakpoints из мг/м³. Концентрации приходят в мкг/м³; переключение мг/м³ — преобразование единиц, не изменение данных. US AQI не имеет единиц концентрации.

Индекс отображается целым. Исправлена пограничная ошибка: например, 50,49 раньше мог показываться как «50» с категорией следующего диапазона. Категория/цвет, рекомендации и порог предупреждения теперь используют тот же округлённый индекс; исходный payload/SQLite не меняются. Для концентраций сохранены дробные значения. [EPA/AirNow](https://document.airnow.gov/technical-assistance-document-for-the-reporting-of-daily-air-quailty.pdf) описывает округление AQI до ближайшего целого; это правило представления, а не выдача модельных данных за официальную станцию.
