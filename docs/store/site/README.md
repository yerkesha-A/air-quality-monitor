# Страницы поддержки и политики

privacy.html, account-deletion.html и support.html генерируются из актуальных документов и контакта разработчика. Без PDF, JavaScript и трекеров; mailto открывает корректный черновик, не отправляет письмо. Страницы пока не развёрнуты: для магазинов нужны доступные HTTPS URL. Публикация на выбранном бесплатном хостинге требует отдельного разрешения владельца. Удаление внутри приложения и альтернативный запрос в поддержку описаны явно.
