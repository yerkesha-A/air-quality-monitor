# Статические страницы

privacy.html и account-deletion.html подготовлены из действующих документов без PDF, JavaScript или трекеров. Они пока не опубликованы. Для Play нужны реально доступные HTTPS URL; публикация на выбранном владельцем бесплатном хостинге требует отдельного разрешения. Контактный mailto открывает черновик, не отправляет письмо. Процедура удаления остаётся ручной и требует реальной обработки разработчиком.
