# Подготовка Data Safety и разрешений

16 ноября 2026. Это подготовленные сведения о коде, а не уже отправленная форма Play Console. Перед отправкой сверить ответы с [User Data policy](https://support.google.com/googleplay/android-developer/answer/10144311) и SDK Firebase.

| Данные | Фактическое использование |
| --- | --- |
| Координаты | Open-Meteo получает выбранную точку; при GPS это координаты устройства. Тайлы OSM показывают область просмотра. Доступ к GPS необязателен, фонового трекинга нет |
| Имя, email, ID | Firebase Auth и облачный профиль своего пользователя; для гостевого мониторинга не нужны |
| Фото | Локальные фото не отправляются в облако; URL фото Google-профиля может быть в профиле, а сетевое изображение загружается с его источника |
| Настройки/избранное | Локальное хранение, при аккаунте — синхронизация Firestore |
| История/заметки | SQLite и приватные файлы устройства; их содержимое не синхронизируется в Firestore |
| Идентификаторы | Firebase Installation/FCM для сервиса уведомлений; регистрация FCM зависит от разрешения |
| Диагностика | Crashlytics в release: ошибки, сведения о приложении и устройстве |
| Финансовые данные/реклама | Платежей, billing и рекламного SDK в приложении нет |

Передача внешним сервисам использует HTTPS. Не отмечать «данные вообще не собираются»: приложение использует сетевые API и Firebase. Определение collected/shared и исключений для поставщиков услуг проверяется по форме Google, а не выводится только из наличия HTTPS.

Удаление предоставляется через запрос разработчику. Согласно [FAQ Google](https://support.google.com/googleplay/android-developer/answer/13327111), допустим путь запроса через поддержку, но он должен быть понятным, доступным и реально обрабатываться. Публичную страницу запроса и контакт нужно проверить перед публикацией. Запросы на удаление пользовательских данных при подготовке проекта не выполнялись.

Android: INTERNET; ACCESS_COARSE_LOCATION/ACCESS_FINE_LOCATION по запросу; POST_NOTIFICATIONS с согласием. Камера и системный photo picker запускаются действием пользователя. Не добавляются background location, широкое управление хранилищем или рекламный ID.
