# Сценарий защиты на 8–10 минут

## 1. Air Quality Monitor

Представлю приложение, его архитектуру и проверенные возможности. Отдельно обозначу ограничения. Время: 30 секунд.

## 2. Задача и аудитория

Цель — помочь понять качество воздуха перед прогулкой. Данные модельные, приложение не является датчиком. Время: 35 секунд.

## 3. Архитектура

Покажу, как экран получает состояние, а репозиторий выбирает API или локальный источник. Время: 45 секунд.

## 4. Карта без платных услуг

Карта работает без Google Cloud billing. Если требуется именно Google Maps, замена нуждается в согласовании преподавателя. Время: 45 секунд.

## 5. Offline-first

Покажу, почему устаревшие данные нельзя выдавать за свежие. Время: 40 секунд.

## 6. Нативные возможности

Android камера, галерея и channel проверены на эмуляторе. На физическом iPhone владелец подтвердил GPS, камеру, выбор фото из галереи и сохранение после перезапуска release без Mac. Физического Android нет. Время: 40 секунд.

## 7. Измерение производительности

Это один парный прогон карты на API 30 с 2 ГБ RAM. Новая карта больше на 59 процентов; raster p95 вырос, доля медленных кадров снизилась. Нельзя утверждать общее ускорение. Я не утверждаю, что все кадры укладываются в 16,67 мс или что доказано отсутствие утечек. Время: 50 секунд.

## 8. DevTools: реальные измерения

Покажу настоящие снимки Performance до и после от 23 ноября. Сырые FrameTiming и память сохранены вместе с описанием стенда и ограничениями. Покажу исходные цифры без обещания стабильных 60 FPS. Время: 20 секунд.

## 9. Тестирование

Тестирую API, состояние, навигацию, SQLite, карту и ошибки. Интеграционные тесты используют отдельный AVD и сохраняют установку. Время: 40 секунд.

## 10. Firebase и безопасность

Email, Firestore и Android FCM проверены; non-fatal build 3 подтверждён в Console 23 ноября. Свежий Google-вход iPhone и сохранение сессии release подтверждены 26 ноября. Удаление аккаунта реализовано в приложении; порядок и ошибки покрыты тестами. Рабочий аккаунт для проверки не удаляется. APNs iOS пока не настроен. Время: 45 секунд.

## 11. CI и выпуск

Последний опубликованный CI 45630653658 успешен. Текущая рабочая копия ещё не отправлена и не имеет нового remote run. Android по просьбе владельца не пересобирался. iPhone release работает без debugger, бесплатная подпись до 3 декабря 2026. Магазины и платные услуги не подключены. Время: 35 секунд.

## 12. Демонстрация приложения

Во время демонстрации не очищаю данные и не меняю существующий аккаунт. На случай отсутствия сети есть реальные скриншоты. Время: 60 секунд.

## 13. Оставшиеся шаги

Android проверен на эмуляторе; физический iPhone release действительно работает. Он не заменяет обязательную Android-приёмку. Обновление бесплатной iPhone-подписи потребуется после 3 декабря. Непроверенные permissions и live iOS Crashlytics учитываются отдельно. Время: 35 секунд.

## Вопросы

- Почему Provider и BLoC вместе? Provider передаёт зависимости и простое общее состояние; BLoC описывает асинхронные события.
- Данные датчика? Нет, модельные оценки CAMS через Open-Meteo.
- Почему OpenStreetMap? Не требует подключения Google Cloud billing; замену нужно согласовать.
- Можно ли гарантировать 60 FPS? Нет, замер на эмуляторе этого не подтверждает.
- Проверен ли физический телефон? iPhone release проверен владельцем; физического Android нет.
- Почему iPhone раньше не открывался с главного экрана? Это ограничение Flutter debug/JIT; установленный AOT release запускается без Mac. Бесплатный provisioning до 03.12.2026.
- Где опубликована сборка? В App Distribution прежний build 2. Android APK/AAB build 3 сохранены; новый iPhone release build 4 установлен локально. Новый push и delivery требуют разрешения.
