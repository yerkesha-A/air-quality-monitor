# Границы проверки Android

Обновлено 23.11.2026. У владельца есть iPhone и MacBook с 8 ГБ RAM; физического Android нет. Это ограничение проверки, а не причина останавливать разработку или подготовку защиты.

| Сценарий | Доступное подтверждение | Физический Android |
|---|---|---|
| Карта OSM, AQI/PM, атрибуция, кэш | Реальные Android tiles/API, integration и release-скриншоты | Не проверен |
| GPS, отказы и отключённая геолокация | Геолокация эмулятора и тесты состояний; координаты emulator geo fix | Реальный GPS не проверен |
| Камера и галерея | Системная камера эмулятора, Photo Picker, сохранение и повторный запуск | Реальная камера/галерея не проверены |
| Kotlin MethodChannel | Настоящий Android channel, сведения SDK, обработка неизвестного метода | Не проверен |
| Email/Firebase/Firestore/FCM | Настоящий тестовый аккаунт, серверное чтение, настоящее push-сообщение | OEM-ограничения фоновой доставки не проверены |
| Release и авторизация | APK/AAB с существующим ключом; установленный release, сохранённая сессия после перезапуска | Установка на телефоне не проверена |
| Crashlytics | Отчёт SDK, транспорт HTTP 200; владелец подтвердил non-fatal событие в Console | Не проверен |
| App Distribution | Загрузка, release notes и рассылка успешны; API возвращает сборку и тестировщика | Установка и запуск на телефоне не подтверждены |
| Производительность | Настоящие profile Performance/Memory и FrameTiming до/после | FPS, память и энергопотребление телефона не измерены |

Наличие тестировщика или его активности в App Distribution не доказывает установку на физическом Android. Принятие приглашения и запуск приложения различаются. APK нельзя установить как iOS-приложение на iPhone. Платный cloud device testing не подключён.

## Режим для MacBook с 8 ГБ RAM

API 37 принудительно выделяет 4096 MiB guest RAM вопреки флагу -memory 2048; он закрыт. Подготовлен отдельный ARM64 Android 11 / API 30: фактически 2048 MiB RAM, два CPU, 720×1600, density 320. Запрошенные 1536 MiB этот образ повышает до 2048 MiB. Фактические параметры подтверждены hardware config и /proc/meminfo. Во время тяжёлой сборки штатно закрывать AVD и сохранять его диск; после сборки закрывать неиспользуемый Gradle daemon. Не держать одновременно профилировщик Chrome и несколько эмуляторов.

Новый облегчённый режим проверен отдельно от уже сохранённых замеров производительности. Старые результаты API 37 / 1080×2400 нельзя выдавать за измерения в новом режиме. Фактическая RAM старого образа была автоматически увеличена эмулятором, несмотря на параметры запуска.
