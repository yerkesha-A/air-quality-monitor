# Источник карты и условия использования

Проверено 16 ноября 2026. Используется flutter_map 8.3.2 и стандартный растровый слой `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.

По [официальной политике OSMF](https://operations.osmfoundation.org/policies/tiles/) приложение отправляет собственный User-Agent с названием и URL проекта, показывает постоянную ссылку «© OpenStreetMap contributors» и использует HTTP-кеш. На Android встроенный дисковый кеш flutter_map ограничен 64 MiB и учитывает заголовки свежести; принудительные no-cache-заголовки не добавляются. Панорама загружает только видимые тайлы (`panBuffer: 0`); устаревшие запросы отменяются. Массовой загрузки регионов и функции prefetch нет.

Это общедоступный сервис без гарантии доступности. Для масштабного публичного распространения необходимо повторно оценить нагрузку и выбрать подходящего поставщика; наличие открытых данных не означает неограниченную бесплатную мощность сервера. URL слоя можно задать при сборке через `MAP_TILE_URL`; при смене поставщика нужно также проверить его лицензию и изменить атрибуцию.

AQI загружается отдельно из Open-Meteo через существующий Repository: не более пяти модельных точек за цикл, debounce 800 мс, последовательная очередь для точек и городов, ограниченный кеш. Эти запросы не являются запросами к серверу OSM.

Google Cloud billing и Maps SDK не используются. Замена Google Maps на OpenStreetMap требует согласования с преподавателем: функциональная карта не доказывает соответствие названию Google Maps в задании.
